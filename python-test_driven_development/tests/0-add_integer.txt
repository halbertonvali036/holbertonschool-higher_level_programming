The ``0-add_integer`` module
============================

Using ``add_integer``:
----------------------

First import the function from the module:

    >>> add_integer = __import__('0-add_integer').add_integer

Normal Usage
------------

Add two integers:

    >>> add_integer(1, 2)
    3

Add positive and negative integers:

    >>> add_integer(100, -2)
    98

Add with default argument `b=98`:

    >>> add_integer(2)
    100

Add float and integer:

    >>> add_integer(100.3, -2)
    98

Add two floats:

    >>> add_integer(2.7, 3.8)
    5

Add large integers:

    >>> add_integer(1000000, 2000000)
    3000000
