The ``2-matrix_divided`` module
===============================

Using ``matrix_divided``:
-------------------------

First import the function from the module:

    >>> matrix_divided = __import__('2-matrix_divided').matrix_divided

Normal Operations
-----------------

Divide a matrix by an integer:

    >>> matrix = [[1, 2, 3], [4, 5, 6]]
    >>> matrix_divided(matrix, 3)
    [[0.33, 0.67, 1.0], [1.33, 1.67, 2.0]]

Verify original matrix is unmodified:

    >>> matrix
    [[1, 2, 3], [4, 5, 6]]

Divide by a float:

    >>> matrix_divided([[10, 20], [30, 40]], 2.5)
    [[4.0, 8.0], [12.0, 16.0]]

Divide matrix containing negative numbers and floats:

    >>> matrix_divided([[-1.5, 2.5], [3.0, -4.2]], 2)
    [[-0.75, 1.25], [1.5, -2.1]]
